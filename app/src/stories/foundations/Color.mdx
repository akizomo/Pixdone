# Color Tokens

**Foundations のこのページ**を、セマンティック色・ビジュアルテーマごとのプリミティブ・利用ルールの**正とします**。  
グローバルな **Gray / Ink / 色相スケールのスウォッチ一覧**だけは、レイアウトの都合で **Design System → Color primitives → [Primitive scales](?path=/story/design-system-color-primitives--primitive-scales)** に分けています（内容の重複ではなく、役割の分割です）。

| 見たいもの | どこへ |
|------------|--------|
| `--pd-color-*` の解決値（表）、テーマ別プリミティブ、`var()` のルール | **このページ** |
| `--pd-gray-*` / `--pd-ink-*` / 各色相のステップをスウォッチで一覧 | **Design System → Color primitives** |

---

Pixdone uses a **Primitive → Semantic** color architecture.

- **Primitive** tokens (`--pd-gray-*`, `--pd-ink-*`, `--pd-purple-*` …) define the raw palette.
- **Semantic** tokens (`--pd-color-surface-page`, `--pd-color-text-primary` …) assign UI meaning and are overridden per color mode and **visual theme**.
- **Components** must only reference semantic tokens — never primitives directly.

## Primitives per visual theme

Arcade / Synthwave / Forest Bit では、テーマTSで定義する専用プリミティブ（`--pd-sw-*`、`--pd-fb-*` など）と、`tokens.css` の共有プリミティブへの参照が異なります。ツールバーでテーマと Color Mode を切り替えると、**その組み合わせで使われるプリミティブ**が次に表示されます。

## CSS変数の使い方

コンポーネントでは `--pd-` プレフィックスのセマンティックトークンを使用する。プリミティブトークン (`--pd-gray-*`, `--pd-ink-*`) は直接参照しない。

```css
/* ✅ 正しい — セマンティックトークンを参照 */
color: var(--pd-color-text-primary);
background: var(--pd-color-surface-page);

/* ❌ 誤り — プリミティブを直接参照 */
color: var(--pd-gray-900);
background: var(--pd-ink-950);
```
