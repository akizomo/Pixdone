# Typography Tokens

Pixdone keeps **readable sans-serif for most text** and uses **pixel/display styles only for selective emphasis** (headings, short labels, counters). Do not make the whole UI pixel-font-heavy.

---

## Live CSS font stacks

Values below follow the Storybook **Color Mode** and **Visual Theme** toolbars (same as the app shell).

## TypeScript source (`typography.tokens.ts`)

Authoritative scale definitions used in TS / components. These do not change when you switch visual theme; runtime text still uses CSS variables in `tokens.css` and legacy `--pd-font-*` where themes override.
