## 7. 提出の前に決める・直すこと

1. **ビルドを上げ直す。** 11/2 に作った iOS 1.0 (2) には、その後に直した次の2件が入っていません。
   - 繰り返しタスクで、1つ完了すると全部完了になる不具合
   - エフェクトギャラリーの「アクティブ」が効かない不具合（スイッチの当たり判定が原因）

   どちらも、直したコードがまだコミットされていません。コミットして、ビルド番号を 3 にして、アーカイブからやり直す必要があります。審査に出すなら、この2件を直してからにしてください。なお、Effects/Themes やアカウントを下層ページにする画面遷移の見直しは、まだ着手していません（出す前に必須ではありません）。
2. **本番ドメイン: `https://pixdone.vercel.app` に決定。** App Store に載せる4つの URL（サポート・マーケティング・プライバシー・規約）は、すべてこのドメインにする。STORE_LISTING.md とアプリの API 接続（`app/src/lib/apiUrl.ts`）はすでにこのドメインで、4つの URL は11/4時点で 200 で開けることを確認済み。審査中も公開後もずっと開ける必要があるので、Vercel のドメイン設定を変えないこと。なお [ENVIRONMENTS.md](ENVIRONMENTS.md) は本番を `https://pixdone.akizony.com` と書いていて（こちらも 200 で開く）、食い違ったまま。どちらかを書き換えるか、別名として残すかは、あとで整理する。
3. **Apple ログインのアカウント削除（トークン取り消し）が未対応。** アプリ内のアカウント削除は実装済みですが、Apple のガイドライン（5.1.1(v)）で、Apple ログインのトークンの取り消しも求められます。Apple Developer で Sign in with Apple のキー（`.p8`）を作って、Firebase に登録する作業が必要です。
4. **審査用のテストアカウント。** 本番に作って、審査メモの仮の文字を差し替えます。
5. **スクショ撮影用に始めた Plus の Web 無料体験を、7日以内に解約する。**
6. **スクショは4枚のままで良いかの最終確認。** 英語版の2枚目の日本語混じりは、そのままにする方針です。
